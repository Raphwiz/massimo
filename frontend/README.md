# Frontend

This folder contains the React/Vite web application:

- `src/` — portal pages, components, API client, and styles.
- `public/` — public assets, including the St. Dorothy crest.
- `vite.config.js` — local development proxy and browser security headers.

Run `npm run dev` from the project root for local development, or `npm run build` to create the production frontend bundle in `frontend/dist`.
